# 3.7 Prompt / Guidance

**Scope**：`agent/features/prompt/**`——Guidance 系统、系统提示构建、上下文注入。
**主触发**：改 `agent/features/prompt/**`。
**次触发**：改 provider 默认 model（影响 guidance 前缀匹配），或改系统提示注入。

## 3.7.1 Guidance 系统

- 当前实现位于 Context-owned prompt adapters 与 Runtime bootstrap prompt assembly；后续迁移 **MUST** 保持 Prompt capability 由 Context Management 独占，**NEVER** 恢复独立 Prompt BC。
- Guidance 文件存放在 `~/.agents/guidance/`：
  - `_default.md` — 所有模型通用。
  - `{prefix}.md` — 按 model id 前缀匹配（一般前缀到最长前缀确定叠加）。
  - `_reasoning.md` — reasoning 开启时附加。
- 首次运行自动生成默认文件，**不覆盖**用户编辑。
- 所有外部 model guidance 文件 **MUST** 经过同一安全扫描入口；builtin fallback **MUST** 与外部文件身份分离。
- Prompt assets **MUST** 在 Session bootstrap 时物化并冻结；Session 内 Main Run、model switch 与 Subagent **NEVER** 重新读取或重建该 stable system prefix。模型或来源变化由 Runtime 产生 typed reminder intent，Context 负责渲染并加入 invocation-only window。
- 每层 user guidance **MUST** 先选 `AGENTS.md`，仅在首选不可用时 fallback `CLAUDE.md`；跨层按全局到项目由远到近全部收集，只按 canonical source identity 去重。
- `ContextPort::build_window` **MUST** 是 Main/Sub Provider-visible system blocks、messages、reminders 与 tool schemas 的唯一生产 owner；Runtime 生成 `ContextWindow` 后只做机械 Provider request 映射。
- “唯一 cache breakpoint”只表示 Context-owned stable system prefix 的唯一逻辑断点；Anthropic adapter **MAY** 另外为 tools 与 message history设置协议级 cache-control。

## 3.7.2 多语言一致性（Config.language）

所有注入 LLM context 的文本 **MUST** 按 `Config.language`（`"en"` / `"zh"`）提供对应语言版本。**NEVER** 在同一 system prompt 中混合中英文（结构性标签如 XML tag name 除外）。

### 3.7.2.1 当前覆盖状态

| 注入路径 | 状态 | 位置 |

| `UNIVERSAL_EXECUTION_DISCIPLINE` | ✅ 已双语（`universal_execution_discipline(lang)`） | `agent/shared/src/i18n/prompt/discipline.rs` |
| TaskUpdate 进度摘要 | ✅ 已双语（Tools Adapter 渲染） | `agent/features/tools/src/adapters/task_update.rs`；仅作为 status 更新的 tool result，不进入 system prompt 或 Provider user-message decoration |

| `build_commit_guidance()` | ✅ 已双语（match lang 模板） | `prompt_build.rs` |
| `currentDate` 段 | ✅ 已双语 | `prompt_build.rs` |

### 3.7.2.2 改造原则

1. **MUST** 在注入文本的函数签名中传入 `language: &str`（或 `Config`），按值选择对应语言版本。
2. **MUST** 为每个文本块定义 `const XXX_EN: &str` 和 `const XXX_ZH: &str`，再通过 `fn xxx(lang) -> &'static str` 选择——**NEVER** 在调用点内联 match。
3. **SHOULD** 优先双语化直接面向 LLM 行为的文本，其次处理反馈性文本（hook 反馈、tool denied、TaskUpdate 进度摘要）。
4. **MUST** invocation-only reminder 只通过 typed intent 进入 `ContextPort::build_window`；Runtime **NEVER** 在 `ContextWindow` 生成后构造 `<task-reminder>` / `<system-reminder>`、写入 `SystemBlock` 或装饰 Provider user message。
5. **MAY** 对纯结构性标签（`<system-reminder>` XML tag name、JSON key name）保持英文不翻译。
